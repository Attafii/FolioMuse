# FolioMuse — Jobs-to-be-Done

Parent document: `docs/product/charter.md`

Format: When [situation], I want to [motivation], so I can [expected outcome].

## JTBD-1 — Learn from real structure (Human gallery)

**When** I'm starting or reworking my portfolio and don't know how to structure it,
**I want to** browse real, attributed examples relevant to my field,
**so I can** understand what sections and patterns typically work, without needing to copy any single example.

**Primary persona:** P2 (Explorer), also P1.
**Non-goal guardrail:** Must not surface a "use this layout" action that duplicates a specific gallery item wholesale (NG1).

## JTBD-2 — Get section-specific feedback (Section intelligence)

**When** I have a draft section of my portfolio (e.g. hero, case study, about),
**I want to** get specific feedback on clarity, completeness, and structure for that section,
**so I can** improve it without rewriting my whole site or guessing what's wrong.

**Primary persona:** P1.
**Non-goal guardrail:** Feedback must reference patterns, not quote/paraphrase a single gallery source verbatim (NG4).

## JTBD-3 — Delegate edits to an agent (MCP agent experience)

**When** I know what change I want (e.g. "make my hero section punchier", "add a new case study"),
**I want to** describe it to an AI assistant and have it apply the change directly to my portfolio,
**so I can** iterate quickly without manually operating every UI control myself.

**Primary persona:** P3, also P1 (as a secondary workflow).
**Non-goal guardrail:** The agent must only ever write the user's own authored/approved content — never insert another user's gallery content directly (NG1).

## JTBD-4 — Validate credibility before publishing

**When** I'm about to make my portfolio public,
**I want to** understand whether it looks complete and credible compared to strong examples in my field,
**so I can** feel confident publishing rather than guessing.

**Primary persona:** P1, P2.

## JTBD-5 — Avoid looking generic or copied

**When** I've used AI assistance and gallery inspiration throughout my process,
**I want to** end up with a portfolio that still feels authentically mine,
**so I can** trust that presenting it publicly won't be seen as derivative or plagiarized.

**Primary persona:** all personas.
**Direct link to originality rules:** `docs/product/originality-rules.md`.

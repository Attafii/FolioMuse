# FolioMuse — Content-Quality Principles

Parent document: `docs/product/charter.md`

These principles apply to: gallery curation, section-intelligence feedback, and any content the MCP agent writes or suggests.

## 1. Specific over generic

Feedback and suggestions must reference the user's actual content ("your hero section lacks a clear outcome statement") rather than generic platitudes ("make it more engaging").

## 2. Pattern-grounded, not source-copied

Section intelligence must derive suggestions from patterns observed across multiple gallery examples, never from a single source verbatim. If a suggestion can be traced to one gallery item's exact wording/structure, it fails this principle (see `originality-rules.md`).

## 3. Attribution is a first-class field, not metadata debt

Every gallery item must carry visible, accurate attribution (creator name/handle, source link, license/consent basis) at all times it is displayed or referenced by section intelligence.

## 4. Feedback must be actionable and scoped

Section-intelligence output must identify: (a) which section, (b) what's missing/weak, (c) a concrete next step. Vague or whole-portfolio feedback that doesn't map to a specific section is out of scope for this pillar.

## 5. Agent-authored content is provisional until accepted

Any content the MCP agent writes or edits on a user's behalf is a proposal until the user (or an explicit auto-accept policy the user has configured) accepts it. Provisional agent edits must be visually/structurally distinguishable in edit history.

## 6. No fabricated credibility signals

Neither the gallery nor the agent may present AI-generated or synthesized content as if it were a verified real-world example (e.g., no fake "used by X companies" style claims).

## 7. Consistency of voice

Section-intelligence suggestions and agent-authored edits must preserve the user's existing tone/voice where content already exists, rather than replacing it with a generic "AI voice."

## 8. Accessibility is a content-quality dimension, not an afterthought

Content suggestions must account for accessibility (e.g., alt text completeness, heading structure, link text clarity) as part of "quality," not a separate audit bolted on later.
